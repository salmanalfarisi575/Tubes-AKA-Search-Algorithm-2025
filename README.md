### Deskripsi Singkat
Proyek ini membandingkan efisiensi waktu (running time) antara algoritma pencarian linear (iteratif) dan pencarian biner (rekursif) menggunakan data stok barang dari ukuran n=1 sampai n=10.000.

### Hasil Analisis (Worst Case)
- **Linear Search:** Memiliki kompleksitas waktu Theta(n) (Linear).
- **Binary Search:** Memiliki kompleksitas waktu Theta(log n) (Logaritmik).
